Day 1 · Radio survey pipelines

From raw LoTSS images to trustworthy model evidence

Learn why the choices made before training—scaling, splitting, augmentation, and class balance—shape every conclusion that comes after it.

Workspace
Google Colab
Data
LoTSS FITS cutouts

What you will learn

Build the pipeline before you build the model.

01
Read the dataset honestly

Audit fixed source-level splits, class imbalance, and why accuracy alone can mislead.

02
Make defensible image choices

Compare FITS scaling routes and decide which augmentations preserve radio morphology.

03
Evaluate class by class

Fine-tune a pretrained vision model, then read macro-F1, recalls, and failure examples.

Before class

Pack these essentials

  • ✓
    5 GB free spaceRoom for the repository and the 1.2 GB archive.
  • ✓
    Google accountThe notebooks run in Colab and use Drive.
  • ✓
    Git + Git LFSA normal clone alone will not fetch the data archive.

Your route

Two sessions, one reproducible story

  1. Session I
    Inspect, scale, augment

    Explore real FITS arrays and export a small preprocessing contract.

  2. Session II
    Transfer, compare, diagnose

    Reuse that contract, train one controlled configuration, and investigate errors.

Day 2 · Graph neural networks for cosmology

Turn the cosmic web into something a network can read

Build graphs from dark-matter halos, use their connections to identify environments, then scale up from one graph to a universe of simulations.

Workspace
Google Colab
Data
CAMELS-SAM halos

What you will learn

Let relationships carry the signal.

01
Build a physical graph

Make halos into nodes and connect nearby neighbors across periodic box boundaries.

02
Classify environments

Predict cluster versus void from graph structure, and compare GraphSAGE with GCN.

03
Infer cosmology

Pool whole graphs to regress Ωm and learn a useful predictive uncertainty.

Before class

Plan the real-data download

  • ✓
    Hands-on 1The real halo catalogue is about 200 MB; pre-download it if possible.
  • ✓
    Hands-on 2Use synthetic graphs with no download, or stage about 5 GB for the real 100-box route.
  • ✓
    Google accountColab installs dependencies in the first cell.

Your route

Move from nodes to entire universes

  1. Hands-on 1
    Cluster or void?

    Learn node classification on one periodic halo graph.

  2. Hands-on 2
    What is Ωm?

    Train on many simulation graphs and add an uncertainty head.

Day 3 · Gamma-ray event reconstruction

Follow an atmospheric shower from camera pixels to predictions

Explore Cherenkov-telescope data, train CTLearn models for three reconstruction tasks, and keep preprocessing consistent when it is time to infer.

Workspace
Conda + Jupyter
Toolkit
CTLearn 0.10.4

What you will learn

Reconstruct events from rich telescope data.

01
Explore the data model

Inspect HDF5 files, calibrated waveforms, camera images, and stereoscopic events.

02
Train three tasks

Predict particle energy, arrival direction, and gamma-versus-proton class.

03
Move safely to inference

Reuse training configuration, write DL2 predictions, and inspect the result.

  2. Train

  3. Predict

Day 4 · Clustering and chemical tagging

Find stellar families in a crowded chemical space

Compare t-SNE, UMAP, and EVoC on APOGEE abundances, score them against kinematic truth, and learn why a beautiful embedding is not automatically a discovery.

Workspace
Docker preferred
Download
≈ 2.2 GB once

What you will learn

Measure discovery, not just visual appeal.

01
Compare three methods

Separate embedding from clustering and understand what t-SNE, UMAP, and EVoC each return.

02
Score against a referee

Use Gaia kinematics as ground truth, then read recall, precision, and kNN purity together.

03
Run a clean experiment

Tune one lever, explain the trade-off, and extend the baseline with one frontier track.

Before class

Day 5 · Imaging interferometry

Reconstruct M87* with a deep image prior

Turn sparse Event Horizon Telescope observables into an image, then ask the scientific question that matters: does the image actually agree with the data?

Workspace
Colab + CUDA
Target
M87* · EHT 2017

What you will learn

Judge an inverse solution in observable space.

01
Read the (u,v) plane

Connect Fourier coverage, visibility amplitudes, closure phases, and angular resolution.

02
Understand the prior

Separate the neural parameterization from explicit smoothness and compactness assumptions.

03
Test robustness

Inspect residuals, change one assumption at a time, and sample with weighted bootstraps.

Before class

Keep three files together

  • ✓
    The Colab notebookYour guided reconstruction and exercises.
  • ✓
    eht_dip.pyModel and optimization code.
  • ✓
    The .npz dataVisibility amplitudes and closure phases.

Your route

Image, forward-model, challenge

  1. Inspect
    Coverage and observables

    Estimate what the baselines can resolve.

  2. Reconstruct
    Optimize one observation

    Use the network as an implicit prior.

  3. Evaluate
    Return to data space

    Compare amplitudes, phases, and residual trends.

  4. Stress-test
    Vary assumptions

    Regularizers, loss, seeds, and bootstrap weights.

Start here

Give Colab a GPU before you run

  1. 1
    Open the tutorial in Colab.

    Choose Runtime → Change runtime type → T4 GPU.

  2. 2
    Run from the top.

    Upload eht_dip.py and the .npz file when prompted.

  3. 3
    Use the quick run first.

    Set QUICK_RUN = True and RUN_BOOTSTRAP = False for the classroom pass.

  4. 4
    Save before leaving.

    Download eht_dip_results.zip; Colab runtimes are temporary.
