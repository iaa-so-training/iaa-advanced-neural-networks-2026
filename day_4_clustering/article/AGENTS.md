# AGENTS.md — article

The workbook students read: a LaTeX document in the Annual Reviews one-column
class, 17 chapters, 65 figures, 51 bibliography entries, and the 56 exercises
that `../src/exercises/` answers.

| Path | What it is |
|---|---|
| `workbook.tex` | The master document — preamble, chapter includes, exercise environments |
| `chapters/*.tex` | 17 chapters, `01_introduction` … `17_conclusions` |
| `figures/` | 65 figures, most generated by `../scripts/make_*_figures.py` |
| `references.bib` | 51 entries — **the single source of truth for citations** |
| `ar-1col.cls`, `ar-style2.bst` | The Annual Reviews publisher template |
| `Makefile` | `make pdf`, `make figures`, `make check`, `make clean` |
| `scripts/` | `check_workbook.py`, `sync_figures.py`, `kmeans_baseline.py` |
| `workbook.pdf` | The built artifact (committed) |

## Building

```bash
cd article
make pdf        # runs `check` first, then latexmk
make check      # validate without building
make figures    # regenerate figures
make clean      # remove LaTeX intermediates
```

LaTeX intermediates (`.aux`, `.log`, `.bbl`, `.fls`, …) are gitignored. Do not
commit them, and do not commit a `workbook.pdf` built from uncommitted `.tex`.

## The bibliography is a contract, not a document

`references.bib` is read at *runtime* by `../src/exercises/citations.py`, which
resolves every citation key in every exercise module. This has consequences
that are easy to miss:

- **An exercise citing a key that is not here raises at import.** That is
  deliberate — a hand-typed "(Smith et al. 2019)" in an answer is exactly the
  failure mode the resolver exists to prevent.
- **Renaming or deleting a key breaks exercise modules**, not just the PDF.
  Grep `../src/exercises/` before touching an existing key.
- **The file must be inside the Docker image.** Exercise modules build their
  reference block at import time, so without it every deck fails at its first
  cell. The `Dockerfile` copies it after `uv sync`.

All 51 entries have been verified to be real, citable works. Adding one means
adding a real reference with a resolvable DOI — not a plausible-looking stub.

## Exercises

The exercises live in the chapter `.tex` files, in numbered exercise
environments. `../scripts/make_exercise_notebooks.py` **parses them out of the
LaTeX** to build the decks, so the workbook is the source of truth for:

- how many exercises exist and their numbering;
- the exact question text rendered into each notebook cell.

Change an exercise's wording here and the decks drift until you regenerate —
which is what CI's `--check` step catches. Add or remove an exercise and you
must also add or remove the matching module in `../src/exercises/`; a test
enforces the correspondence in both directions.

## Figures

Most figures are generated, not drawn: `../scripts/make_results_figures.py`,
`make_teaching_assets.py`, `make_masked_ae_figures.py`, `make_sky_images.py`.
`scripts/sync_figures.py` keeps the figure directory in step.

Figures must be **matplotlib** — a plotly figure cannot be exported into LaTeX.

## Numbers in the prose

Every number stated in the workbook came from a real run, and where the
workbook quotes a result it is reproducible from the recorded reference runs in
`../docs/reference_runs/`. Several passages deliberately report that a
published number does **not** reproduce; those discrepancies are the teaching
material, not errors to be corrected into agreement.
